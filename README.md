# AquaIQ 💧

AI-based Water Demand Forecasting System for Smart Campus Operations.

---

## 🚀 Overview

AquaIQ is a full-stack system that predicts campus water demand and optimizes pump scheduling to reduce energy usage and improve distribution efficiency.

---

## ⚙️ Features

* 📊 Water demand prediction using XGBoost
* 🌦️ Weather-aware forecasting (temperature, rainfall)
* ⚡ Pump scheduling optimization
* 🏗️ Tank level monitoring with alerts
* 📈 Interactive dashboard with real-time data

---

## 🧠 Tech Stack

* Backend: Flask
* ML: XGBoost, Scikit-learn
* Frontend: HTML, CSS, JavaScript (Chart.js)
* Data: Time-series + simulated campus data
